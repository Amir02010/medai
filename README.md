# MedAI — умный помощник по здоровью

Веб-приложение и Telegram Mini App на одном коде. Разбирает симптомы,
показывает, в какой аптеке рядом есть нужное лекарство и по какой цене,
находит больницы, подсказывает нужного специалиста, напоминает о приёме
лекарств. Узбекский, русский, английский. Светлая и тёмная темы.

Стек: Create React App (JavaScript, JSX, CSS), zustand, react-router.
Без Vite, без TypeScript, без Python. Бэкенд — одна serverless-функция Vercel.

---

## Запуск за две минуты

```bash
npm install
npm start
```

Откроется `http://localhost:3000`. ИИ при этом работает в демо-режиме
(отвечает по шаблонам) — это нормально, приложение полностью рабочее.

Чтобы ассистент отвечал по-настоящему, нужна serverless-функция:

```bash
npm i -g vercel
cp .env.example .env.local      # вписать AI_API_KEY
vercel dev                      # фронт + /api/chat вместе
```

## Публикация

```bash
vercel --prod
```

Затем в **Vercel → Settings → Environment Variables** добавить:

| Переменная | Значение |
|---|---|
| `AI_PROVIDER` | `gemini`, `anthropic` или `openai` |
| `AI_API_KEY` | ваш ключ |
| `AI_MODEL` | необязательно |

Где взять ключ:

| Провайдер | Где | Цена |
|---|---|---|
| `gemini` | aistudio.google.com/apikey | есть бесплатный тариф, карта не нужна |
| `anthropic` | platform.claude.com/settings/keys | от $1 / $5 за 1M токенов |
| `openai` | platform.openai.com/api-keys | от $0.20 / $1.20 за 1M токенов |

И нажать **Redeploy**. Всё. Ключ живёт только на сервере и в браузер
не попадает никогда.

## Как поставить свой логотип

1. Положите файл в `src/assets/` — лучше `logo.svg`, можно png.
2. Откройте `src/components/Brand/Logo.jsx` и раскомментируйте две строки
   вверху файла:

   ```js
   import logoSrc from "../../assets/logo.svg";
   const CUSTOM = logoSrc;
   ```

3. Всё. Логотип заменится сразу везде: боковая панель, шапка, экран входа,
   аватар ассистента в чате, пустой чат, страница 404.

Размер подставляется автоматически, фон и скругление берутся из CSS.
Отдельно замените `public/favicon.svg` и пересоберите иконки `logo192.png`
и `logo512.png` — они видны на вкладке браузера и при установке на телефон.

## Возможности

**Персонализация.** Медкарта (возраст, пол, хронические, аллергии, постоянные
лекарства) уходит в системный промпт. ИИ учитывает аллергии и взаимодействия —
это главное отличие от обычного чата с нейросетью.

**Триаж красных флагов.** «Боль в груди», «не могу дышать», «отнялась рука»,
мысли о суициде — распознаются локально, до обращения к модели, на всех трёх
языках. Показывается экран со звонком 103. Работает даже без интернета.

**Схема тела.** Клик по месту боли → сила → длительность → что обычно смотрят,
к какому врачу идти, какие признаки требуют срочной помощи. Грудная клетка
всегда помечается как срочная.

**Выжимка для врача.** Из диалога собирается структурированная справка: жалобы,
хронология, что уже пробовали, вопросы врачу. Копируется в один клик.

**Фото лекарства или рецепта** — отправляется в модель со зрением.

**Лекарства и напоминания** с расписанием и процентом соблюдения курса.

**Семейные профили** — отдельная медкарта на каждого, ИИ переключает контекст.

**Поиск лекарств с ценами.** Каталог препаратов по категориям, поиск по
названию и действующему веществу. Нажатие на препарат показывает, в каких
аптеках он есть и по какой цене — список отсортирован от дешёвого к дорогому,
самое выгодное предложение помечено. Рецептурные препараты помечены отдельно
с предупреждением. Из карточки — маршрут, звонок в аптеку, добавление в свою
аптечку и вопрос ассистенту про препарат.

**Регион.** Пользователь выбирает свой регион (или определяется по
геолокации) — и видит только аптеки рядом. Если препарата в регионе нет,
одной кнопкой раскрывается поиск по всему Узбекистану, чтобы можно было
заказать.

**Аптеки и больницы рядом** — на одной странице с переключателем. Аптеки:
режим работы, 24/7, рейтинг, расстояние по прямой, маршрут, звонок. Больницы:
скорая, многопрофильные, поликлиники, роддома, детские — с фильтром по типу
и блоком вызова 103 сверху.

**Врачи** — фильтр по специальности, рейтинг, запись на слот.

**Telegram Mini App** — BackButton, вибрация, цвет системных панелей, вход по
`initData`. Тот же код работает обычным сайтом.

**PWA** — ставится на телефон, открывается офлайн.

## Безопасность и устойчивость

- Ключ модели только на сервере, rate-limit 20 запросов в минуту на IP
- Заголовки безопасности в `vercel.json`
- Данные пользователя хранятся локально, экспортируются и удаляются одной кнопкой
- Повреждённое хранилище само вычищается — приложение не падает
- `ErrorBoundary` вместо белого экрана
- Системный промпт запрещает диагнозы и рецептурные дозировки, при неотложных
  признаках первой строкой отправляет в 103

**Доступность:** axe-core, правила WCAG 2.1 уровня AA, 11 страниц × 2 темы —

**Вёрстка:** 3 языка × 2 темы × 5 ширин экрана (360, 414, 768, 1280, 1680) ×

(40 px на сенсорных экранах).

**Размер:** первая загрузка 113 kB JS + 6 kB CSS в gzip. Страницы подгружаются
по мере перехода. Весь набор чанков — 186 kB.

## Что осталось подключить

UI под это готов — нужен только бэкенд:

1. **Авторизация.** `Login.jsx` пускает по любому паролю. Варианты: Supabase Auth
   (быстро) или проверка Telegram `initData` на сервере.
2. **Каталог аптек и врачей.** `src/data/catalog.js` — статический массив.
   Формат полей боевой: замените на ответ API, UI менять не придётся.
3. **Наличие и цены лекарств.** Поле `stock` у аптеки и каталог
   `src/data/medicines.js` — заглушка. Нужна выгрузка из систем аптек
   (1С, MyTaxi-подобные API аптечных сетей) или ручная панель для аптек.
4. **Напоминания в фоне.** Сейчас это список в приложении. Для настоящих
   уведомлений: Telegram-бот (проще всего) или Web Push.
5. **Оплата Pro.** Экран тарифов есть, платёжного провайдера (Payme / Click /
   Telegram Payments) нет.

## Юридическое

Приложение не ставит диагнозы и не назначает лечение — это зафиксировано
в системном промпте, продублировано в интерфейсе и описано в документах.

Условия использования и политика обработки данных лежат в `src/data/legal.js`
на трёх языках и открываются по адресам `/legal/terms` и `/legal/privacy`.
Это рабочая заготовка, написанная по тому, как приложение реально устроено.
Перед публичным запуском подставьте свои реквизиты и покажите тексты юристу.
